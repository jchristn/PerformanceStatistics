Since 2026-10-07, the PerformanceStatistics scope (scp_muyjg6zy_IOIIvK4fT8eKj9dIR0C) is mirrored at <repo>/.okf/. session_start reported that the NotDory server can't see /Users/joelchristner/Code/PerformanceStatistics, so filesystemMirror is off and agents maintain the bundle by hand. The format is the same as the NotDory repo's own .okf, which is generated by NotDory's OkfDocument and FilesystemMemoryStore.

Layout:
- `.okf/<categoryId>/<slug>.md`
  - Frontmatter keys, in order: type, title, description (= summary), timestamp (= lastUpdateUtc), status: "deprecated" (only when superseded), created, slug, category (= categoryId), links (JSON array), supersededBy (the replacing memory's id, only when superseded), version, salience.
  - Every scalar is double-quoted. Timestamps use the .NET "O" format with 7 fractional digits and a Z.
  - The body follows the closing --- verbatim.
- `.okf/index.md`
  - Frontmatter is only `okf_version: "0.2"`.
  - One "# <categoryId>" section per category, sorted case-insensitively.
  - Each section has "* [title](<categoryId>/<slug>.md) - <description>" lines, sorted by path, with " (deprecated)" appended for superseded memories, then a blank line.

How to apply:
1. After memory_upsert or memory_delete, enumerate the scope (memory_enumerate) and rewrite the affected files and index.md.
2. When a memory supersedes another, rewrite the old file with status "deprecated" and supersededBy.
3. Commit .okf/ together with the code it describes.
